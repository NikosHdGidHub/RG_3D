# 🚀 Ракетный Пинок 3D

```markdown
# 🚀 Ракетный Пинок 3D

> **Пни ракету. Доберись до космоса. Найди свой идеальный угол.**

Полноценная 3D-игра про полёт ракеты с процедурной генерацией мира, физикой на 120 Гц и глубокой системой прогрессии. Разработана на TypeScript + Vite + Three.js, опубликована на Яндекс Играх.


```

## 🎮 О чём игра

Босс стоит на стартовой площадке и ждёт, когда ты дашь команду «Пнуть!». Ракета взмывает в воздух — и дальше всё зависит от тебя. Управляй носом ракеты, лови правильный угол, жги топливо, активируй форсаж, окислитель, собирай сундуки и гемы, прокачивайся — и однажды доберись до звёзд.

**Цель:** пролететь как можно дальше за один запуск.

```
       🚀
      /
     /
    🦵  ← Босс
   /│\
```

## ✨ Особенности

### 🏗️ Технологии

| Слой | Что используем |
|---|---|
| **Язык** | TypeScript 6.0 (strict, `verbatimModuleSyntax`) |
| **Сборка** | Vite 8.3 |
| **Рендер** | Three.js 0.186 |
| **Физика** | Собственная, фиксированный шаг 120 Гц с интерполяцией рендера |
| **Параллелизм** | Web Workers для генерации чанков и LOD |
| **Хранение** | localStorage (прогресс, призрак, настройки) |
| **Реклама** | Yandex Games SDK v2 |

## 🕹️ Управление

| Действие | Клавиатура | Тач |
|---|---|---|
| Поворот носа | `W` / `S` | ▲ / ▼ |
| Тяга | `Space` (удерживать) | 🔥 PUSH |
| Окислитель | `E` | 💧 |
| Форсаж | `F` | 🚀 |
| Запуск ракеты | `Space` в фазе ready | «Пнуть!» |

## 🚀 Быстрый старт

### Требования

- **Node.js** 20+
- **npm** 10+
- Современный браузер (Chrome / Firefox / Safari / Edge)

## 🧮 Калькулятор траекторий

Отдельная страница (`/calculator/`) для симуляции и оптимизации билда:

- **Один билд** — таблица «что купить дальше?», ROI каждого апгрейда в метрах на 1000 валюты
- **Оптимум** — двухфазный поиск лучшего угла × стратегии тяги
- **Сравнить два** — A vs B с разницей в метрах
- **Найти прирост** — «+1 карточка» через Web Worker пул
- **Графики** — траектория и «дальность vs угол»

Открой `Game/calculator/` после `npm run dev`.
